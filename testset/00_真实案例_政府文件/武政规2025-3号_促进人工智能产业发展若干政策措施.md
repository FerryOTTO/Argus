# 武汉市促进人工智能产业发展若干政策措施

- 文号：武政规〔2025〕3号
- 发文机关：武汉市人民政府
- 成文日期：2025年2月12日
- 发布日期：2025年2月18日
- 施行日期：2025年3月19日（有效期2年）
- 来源：https://www.whkjgzz.com/zcfg/158.html（武汉科技工作者公共服务平台转载市人民政府文件）

## 核心内容（真实原文节选）

为抢抓人工智能发展机遇，加快建设武汉国家人工智能创新应用先导区，打造国内一流的人工智能创新集聚区和产业高地，特制定本政策措施。

**一、支持关键技术突破**：组织实施市级科技重大专项，给予单个项目最高2000万元资金支持；每年在市重点研发计划布局一批人工智能项目，单个项目最高100万元；对牵头承担国家科技重大专项、重点研发计划的企业给予配套奖励。

**二、强化普惠算力供给**：每年设立总额不低于1000万元的算力服务券，重点支持中小企业，对使用算力服务费用给予50%、最高20万元补助，补助期限不超过三年。

**三、增强模型创新能力**：围绕电子信息制造、工业质检、教育、医疗、遥感、文创、金融等领域每年遴选垂直行业模型，对牵头研发单位按研发成本30%给予最高500万元补助，并对其使用算力费用给予每年50%、最长三年、累计最高500万元补助。

**四、支持公共服务平台建设**：对开源开放、协同共享的人工智能公共服务平台，按实际建设投入30%给予最高500万元；对中试平台给予最高1000万元资金支持。

**五、促进数据开发利用**：每年发布高质量数据集建设任务专项，每个专项最高200万元奖励；对利用数据产品起到关键显著作用并通过评审的机构，给予最高200万元补助。

**六、推动应用场景开放创新**：每年遴选人工智能示范应用场景项目，按总投入30%给予最高100万元；对首次获批国家人工智能领域揭榜优胜单位、卓越级智能工厂、领航级智能工厂的企事业单位，给予100万元奖励。

**七、支持产业集聚发展**：打造2—3个人工智能核心产业园区；对获评国家中小企业特色产业集群的区，每个集群500万元、单个区最高不超过1000万元奖励。

**八、支持高端人才引育**：符合条件的重点用人单位纳入武汉英才计划举荐单位名录。

**九、加强科技金融赋能**：汇聚形成人工智能百亿基金投资生态。

## 归档（`归档/`）

历史设计稿，按版本递进保留，可以看清访问控制模块的演进过程：

| 目录 | 内容 |
|---|---|
| `设计稿v1/` | 最早的 Clawguard 技术文档 |
| `设计稿v2/` … `设计稿v7/` | 访问控制模块 v2 → v7 的设计、规则文件与验证脚本 |
| `调研/` | 创新点调研、规则完善方案 |
| `参考_ccswitch组件/` | 参考用的前端组件（供应商卡片、用量看板、趋势图） |

> 归档目录中，`设计稿v1/auth-gateway-extracted/` 与
> `ClawguardV2.1-main_旧快照/` 在整理仓库时**已移除**：
> 前者是解压出来的旧服务副本，内含私钥、`.env` 与测试数据库；
> 后者是 `terminal/` 的过时快照，保留只会造成两份代码混淆。
> 需要的可以到原开发机的 `docs/归档/` 取回。
